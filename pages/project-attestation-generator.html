Attestation Generator

Projet pro — Générateur PDF

Description du projet

Outil interne créé pour générer automatiquement une attestation de restitution du matériel au format PDF, afin d’éviter les modifications manuelles répétitives.

Fonctionnalités principales

  • Formulaire de saisie (nom, adresse, date, matériel, etc.)
  • Génération instantanée de l’attestation en PDF
  • Téléchargement direct du document final
  • Standardisation du document et réduction des erreurs

Technologies utilisées

HTML CSS JavaScript PDF
