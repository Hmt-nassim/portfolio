Projet pro — Accompagnement utilisateurs

Description du projet

Réalisation de vidéos et de procédures pour aider les gestionnaires de l’entreprise à mieux utiliser les outils informatiques, sur site ou en TTV.

Contenus produits

  • Tutoriels simples (raccourcis, manipulations quotidiennes)
  • Guides pratiques pas à pas pour les utilisateurs
  • Supports sur des sujets plus avancés (VPN, changement de passerelle)
  • Ressources réutilisables pour faciliter l’autonomie

Apport métier

Formation Pédagogie Support utilisateurs Documentation IT
